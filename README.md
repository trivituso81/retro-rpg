# Tom's Village

A cheeky 16-bit JRPG proof of concept. You play as **Tom** (X-Men tee and all) in a tiny village full of houses, residents, and inside jokes.

## Play

```bash
npm install
npm run dev
```

Open the local URL Vite prints.

**Desktop:** WASD / arrows to walk, Space / E / Enter to talk.

**iPhone:** Open in Safari (or Add to Home Screen for full-screen). Use the on-screen **D-pad** to walk and **TALK** / **NEXT** (or tap the screen) for dialogue. Safe-area aware for the home indicator / notch.

## PoC scope

- Tom walks a small village built from Puny World (CC0) tiles
- A handful of houses, a well, and signs you can inspect
- Residents with multi-line gag dialogue
- Tom's sprite sheet from the attached character model

Not in this PoC: combat, inventory, interiors, or the old overworld continent.

## Triple-tap reset

Tap the top-right corner three times to clear the saved position and respawn in the square.
